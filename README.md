# Subtitle Studio

Десктопное приложение для работы с субтитрами: правка таймкодов, перевод, транскрипция, экспорт. Главное отличие от обычного редактора - встроенный ИИ, который учитывает контекст проекта (соседние реплики, глоссарий, события в эпизодах/фильмах проекта), и агент в боковой панели: с ним можно обсудить реплику и попросить внести правки прямо в субтитры. Сделано на Tauri и React.

Один проект - это не обязательно один ролик. Можно собрать в нём все серии сериала или несколько частей фильма: в дереве проекта у каждой серии своё видео и свой файл субтитров, а глоссарий и контекст для ИИ общие на весь проект.

В разделе **Releases** лежит готовый установщик MSI для Windows.

## Системные требования

- CPU от 2.5 ГГц (лучше четырёхъядерный и выше)
- RAM от 8 ГБ (рекомендуется 16 ГБ)
- Экран от 1280×720 (лучше 1920×1080); для режима видео на втором мониторе — второй дисплей
- Звуковая карта и колонки/наушники
- Свободного места на диске: от 8 ГБ

**ПО**
- Windows 10 (64-bit) или новее
- Microsoft Edge WebView2 Runtime (установщик подтянет при необходимости)
- Для функций ИИ — интернет и ключ OpenAI API

## Что умеет

**Редактор**
- Таблица реплик с таймкодами, оригиналом и переводом
- Таймлайн с волной аудио, перемоткой по клику и правкой границ сегментов
- Редактор выбранной реплики под таблицей
- Просмотр видео с наложением субтитров (оригинал можно включить отдельно)
- Отмена и повтор правок, поиск и замена, проверка орфографии (русский и английский)
- Глоссарий терминов для проекта
- Импорт видео (mp4, mkv, mov, avi, webm) и готовых субтитров (srt, vtt)
- Экспорт в SRT, ASS, VTT, TXT, PDF
- Режим двух мониторов: видео на втором экране

**ИИ** (нужна активация через ключ OpenAI API)
- Транскрипция через Whisper
- Перевод пакетом с учётом глоссария и подсказок
- Перетранскрипция выделенного фрагмента на таймлайне
- Пошаговый мастер: видео → субтитры → перевод
- Агент в боковой панели: правки по запросу, замена терминов, обсуждение реплик

## Первый запуск

При старте можно активировать приложение ключом OpenAI API или закрыть окно и работать как с обычным редактором субтитров.

После активации доступны все функции из меню «ИИ», мастер в боковой панели и агент. Без активации функции ИИ недоступны.

Язык интерфейса и тема в **Файл → Настройки**.

## Как работать с проектом

1. **Файл → Новый проект** - укажите имя и папку. Либо откройте существующий.
2. Импортируйте видео для каждого видеофайла: **Файл → Импорт видео** (можно добавлять сколько угодно файлов в один проект). Для первой серии удобен мастер в боковой панели.
3. Субтитры: импортируйте готовый файл, напишите вручную или получите через транскрипцию/мастер.
4. Правьте текст и таймкоды в таблице, на таймлайне или в нижнем редакторе.
5. **Экспорт сразу нескольких** в боковой панели - выберите файлы и формат. Отдельные SRT файлы сохраняются в папке проекта.

### Таймлайн

| Действие | Клавиша |
|----------|---------|
| Вставить пустой субтитр | A |
| Поставить начало | S |
| Поставить конец | D |
| Разделить реплику | F |
| Пауза / воспроизведение | Пробел |

Зум — ползунок внизу таймлайна или Alt + колёсико мыши.

## Сборка из исходников

Нужны Node.js, Rust, Python 3 (для ML-сайдкара при полной сборке).

```bash
npm install
npm run tauri dev          # разработка
npm run release:win        # установщик MSI для Windows
```

Полная release-сборка подтягивает ffmpeg, Python-окружение и дополнительные модели обработки аудио (~2 ГБ в установщике). Перед `release:win` положите `ffmpeg.exe` и `ffprobe.exe` в `src-tauri/bundle-extra/bin/`.
