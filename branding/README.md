# Иконки приложения

Нужны **два файла** — больше ничего вручную не трогайте.

| Где видно | Файл | Размер |
|-----------|------|--------|
| Верхний левый угол окна | `src/assets/app-logo.png` (или `.svg`) | 24×24 |
| Панель задач Windows, установщик | `src-tauri/icons/icon.ico` | один `.ico` |

## Как поменять логотип в интерфейсе

Положите картинку в `src/assets/app-logo.png` (24×24) и в `App.tsx` импортируйте её вместо `app-logo.svg`, если нужен PNG.

## Как поменять иконку в таскбаре

**Вариант А** — положите готовый `icon.ico` в `src-tauri/icons/icon.ico`.

**Вариант Б** — из одного квадратного PNG (512×512) в `branding/icon.png`:

```bash
npm run icons:taskbar
```

Скрипт соберёт только `icon.ico` и удалит лишние файлы (iOS/Android и т.д.), которые создаёт `tauri icon` по умолчанию.
